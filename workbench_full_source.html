# Gomaa - Shastra Dhaara

Canonical Ayurvedic Shat Kriya Kala Model Engine & Interactive Diagnostic Workbench.

## Repository Overview
This repository provides a zero-dependency, standalone decision engine for evaluating disease stage progression (*Shat Kriya Kala*) based on classical *Ashtavidha Pariksha* observational inputs.

## Key Features
- **Deterministic Rules Engine:** Maps ocular, tongue, and digestive parameters to Dosha vectors.
- **Client-Side ZIP Generator:** Pure binary array zip compiler executing directly in the browser.
